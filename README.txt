Black Vich Mobile  —  کلاینت اندروید
=====================================
این برنامه خودش هیچ داده‌ای ندارد؛ فقط به سرور روی کامپیوتر (همان برنامه‌ی ویندوز) وصل می‌شود.
بعد از اتصال، صفحات آشپزخانه همان سرور داخل برنامه باز می‌شوند، پس
همه‌ی امکانات دقیقاً مثل نسخه‌ی ویندوز است (و با هر آپدیتِ سرور، موبایل هم آپدیت می‌شود).

طرز کار
-------
1) روی کامپیوتر BlackVich را اجرا کن (مرکز کنترل → لینک و QR).
2) گوشی روی همان وای‌فای باشد.
3) برنامه را باز کن: لینک را بچسبان یا QR را اسکن کن. اتصال ذخیره می‌شود و دفعه‌ی بعد خودکار وصل می‌شود.

ساخت APK
--------
روش ۱ (ساده): پوشه را در Android Studio باز کن → Build > Build APK(s).
  خروجی: app/build/outputs/apk/release/app-release.apk
روش ۲ (ترمینال): اگر Gradle 8.7+ و Android SDK 34 داری:
  gradle assembleRelease

فونت وزیرمتن
------------
فایل فونت Vazirmatn را (با هر اسمی، فرمت woff2 یا ttf) داخل این پوشه بگذار:
  app/src/main/assets/fonts/
برنامه خودش آن را پیدا می‌کند. اگر نباشد، با فونت پیش‌فرض گوشی کار می‌کند.

نکته‌ها
-------
- اگر ویندوز پرسید «اجازه‌ی شبکه»، روی Allow بزن (فایروال).
- اگر IP کامپیوتر عوض شد، لینک/QR جدید را وارد کن.
- نسخه‌ی iOS ندارد؛ آیفون می‌تواند همان لینک را در Safari باز کند و Add to Home Screen بزند.

ساخت APK بدون Android Studio (GitHub Actions)
---------------------------------------------
1) یک repository جدید در GitHub بساز و کل محتویات این پوشه را (با ساختار پوشه‌ها) آپلود کن.
2) تب Actions → Build APK → Run workflow.
3) بعد از چند دقیقه، فایل APK را از قسمت Artifacts دانلود کن (BlackVich-APK).
